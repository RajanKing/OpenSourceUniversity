# FDE Vault Digest — Everything in This Folder, Summarized

This vault is a personal study knowledge base for becoming an **AI Forward Deployed Engineer (FDE)** — the Palantir-style role that combines hands-on engineering with customer discovery, integration, deployment, and ownership of delivered outcomes. The vault has two halves:

1. **`roadmap by fde/`** — a machine-generated, meticulously validated study system built from a 2026-10-23 snapshot of the official [roadmap.sh Forward Deployed Engineer roadmap](https://roadmap.sh/forward-deployed-engineer) (94 topics → 44 sub-roadmaps → 5,044 learning nodes → 331 curated resource links), plus an Excel study planner and a capstone playbook.
2. **Everything else** — hand-collected study notes and handbooks clustered around four themes: AI engineering curricula, AI-native development, the 2017 Transformer paper (explained four different ways), and a Scaler AI-FDE course (173 sessions).

### What every topic note contains (`Topics/`, 94 files, all `status: not-started`)

A strict template: definition + FDE relevance → 4–6 concepts to understand → an **applied exercise** (with a sandbox-safety warning) → a **common failure mode** (e.g. RAG: "retrieving relevant but *unauthorized* material and treating citations as proof of correctness") → **evidence of mastery** with checkboxes → original roadmap resources (linked to local `Resources/R###` notes) → graph connections → provenance → empty "My Evidence" fields to fill in.

The design philosophy throughout: **watching a course is an input, not proof — every completed topic needs an artifact** (a design, test, dataset audit, measured result, runbook, or UAT record).

### The recommended learning order (from `00 Start Here` + `FDE Roadmap.md`)

Role orientation + a real workflow problem → thin full-stack slice → enough data engineering to trust inputs → retrieval + model evaluation → bounded tools/agents only when the task requires actions → authorization, operational ownership, business measurement before calling it "production." Discovery, communication, privacy, and security run throughout — their bottom-of-roadmap placement doesn't mean "do them last." Pick **one language, one frontend approach, one cloud**.

## How to use this vault (suggested)

1. **Orient:** `roadmap by fde/00 Start Here.md` → `FDE Roadmap.md` intro → `FDE/AI FDE Master Roadmap.md` (your 18-stage plan).
2. **Plan:** open the Excel planner, set hours/allocations, follow `08 Study Plan and Practice.md` for practice platforms and parallel-study rules.
3. **Study:** work the 9 tracks; for each topic, do the applied exercise and record an artifact in "My Evidence". Dive into sub-roadmaps only when a project needs them.
4. **Build:** the capstone in `04 Capstone and Delivery Playbook.md` is the integrating deliverable.
5. **Go deep on AI:** the handbooks (Clusters A–C) supply the theory the roadmap assumes; the Discovery guides (Cluster E) supply the consulting craft.
