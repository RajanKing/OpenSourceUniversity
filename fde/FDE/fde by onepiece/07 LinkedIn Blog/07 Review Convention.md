# 🔍 07 Review Convention — Before Anything Is Pasted

Every post passes the Quartermaster's gate: a self-review (by the drafting agent/writer) logged in the post's bottom **Review block**, then a **human review** (the Captain / company reviewer) whose ✅ flips Tracking to Approved. [P1] blocks publication; [P2] blocks unless waived with a stated reason; [P3] never blocks.

## The checklist (run in order)

### A. Substance
- [ ] **Audience layers:** TL;DR (exec) · ELI5 + glossary (fresher) · body + ☠️ (practitioner) · 🏛️ org section (founder/CTO) — all present and genuinely serving.
- [ ] **Assumptions & scope box** present and true (level, prerequisites, versions).
- [ ] **Math gate** (where math exists): every formula has all six steps — claim, formal statement w/ symbols, numbered derivation, **worked numeric example recomputed by the reviewer**, assumptions/breaks, practice. Each derivation step re-derived independently.
- [ ] **Honesty:** no fabricated statistics/quotes/incidents; illustrative scenarios labeled; execution claims real or labeled unexecuted; no "you now know X".
- [ ] **Coverage note** (F-series): every curriculum-matrix sub-item visibly taught and mapped.

### B. LinkedIn mechanics
- [ ] Copy block contains **no wikilinks, no embeds, no attachments** — full URLs only; links live (open each).
- [ ] Image markers `📷 [IMAGE n]` match actual files in `08 Images/`, converted to PNG, correct size class, alt text written.
- [ ] Article length 1,500–2,500 words (math-heavy F ≤ 3,000 or split); teaser 1,000–1,500 chars.
- [ ] Hashtags: 3–5 from [[fde by onepiece/07 LinkedIn Blog/06 Tags|Tags]], series anchor included, teaser-only.
- [ ] Paste plan noted: LinkedIn Article editor quirks (re-apply bold/headings; tables often need screenshots — decide per table and note it).

### C. Voice
- [ ] Professional voice; flavor ≤ one line per major section; zero flavor inside math/code/tables/org sections; sign-off present once.
- [ ] No gatekeeping, no hype; every org recommendation carries a cost or risk.

### D. Bookkeeping
- [ ] Frontmatter tags correct (track/post/family/status).
- [ ] [[fde by onepiece/07 LinkedIn Blog/09 Tracking|Tracking]] row and [[fde by onepiece/07 LinkedIn Blog/04 Index|Index]] row updated; status values consistent.

## Review block format (bottom of every post, Zone A — never inside the copy block)

```markdown
## 🔍 Review log
Self-review (date, by): findings — [P1|P2|P3] section — issue — resolution.
Human review (date, by): findings — …
Captain ✅ (date, by): approved for publish / changes requested.
Paste notes: e.g., "table 2 → screenshot; banner PNG from 08 Images; hashtags from role-glossary set."
```

## Standing paste checklist (at publish time, not draft time)

1. Open LinkedIn → *Write article*. 2. Paste the copy block; re-apply headings/bold where the editor strips them. 3. Upload PNGs at markers. 4. Tables the editor mangles → replace with the prepared screenshot. 5. Set the banner as the article's hero image. 6. Publish the teaser as a feed post linking the article. 7. Record URL in Tracking; flip Index.
