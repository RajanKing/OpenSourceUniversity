# 📣 Publishing and Repurposing — One Chapter, Five Products

A chapter is a **master asset**; publishing derives channel-specific products from it. Nothing ships before ✅ Approved; everything that ships is recorded in the [[fde by onepiece/04 Linking Index/Chapter Index|Chapter Index]] and the [[fde by onepiece/05 Production Pipeline/03 Status Tracker|Status Tracker]].

## Channel matrix

| --- | --- | --- | --- | --- |

## Naming and metadata conventions (all channels)

- **Title pattern:** `Day NNN — <Topic> | Pirate Code Ventures · FDE <Saga name>` (blog/notes); video: `FDE Day NNN: <Topic>, taught by pirates`.
- **Description first line:** the day's one-sentence promise + link to the [[roadmap by fde/00 Start Here|roadmap]] and previous day.
- **Tags:** `FDE, forward deployed engineer, <topic>, <saga>, one piece, learn to code`.
- Thumbnail/poster: island color + bounty poster of the day's skill (see saga palette below).

**Saga palette (thumbnails/posters):** Dawn=amber · Shimotsuki=steel blue · Arlong Park=ocean teal · Skypiea=sky gold · Thriller Bark=violet · Water 7=city orange · Impel Down=crimson · Baratie=warm red · Whole Cake=pink · Laugh Tale=white/gold.

## Publish checklist (per chapter, per channel)

1. Status ✅ Approved in Tracker; review file closed.
2. Products rendered from the FINAL chapter version (never a draft).
3. Links: previous/next day, playlist/series page, roadmap source note.
4. Accessibility: captions on video; alt text on diagrams; code as text, not images.
5. Record: publish date + links in Tracker row and Chapter Index bounty row; bump `days-written`.
6. Announce per community convention (optional): one clip + one teach-it-back question.

## Post-publish maintenance loop

1. **Signal sources:** comments, errata reports, reader quiz answers, analytics drop-off points.
2. **Triage (Maintainer):** factual error → fix chapter, log in Maintenance log, mark 🛠️, decide re-publish (blog trivially; video via pinned correction/comment unless severe). Clarity issue → backlog a "refresh" note; batch refreshes per saga.
3. **Feedback → curriculum:** recurring confusion about topic X feeds the NEXT chapter's Clinic or a P2 note; systemic confusion → Tone Guide / Content Flow change proposal.
4. **Evergreen rule:** published days are never silently rewritten — changes are logged with date and reason; readers' citations must stay valid.
