# 🔍 Reviews — One File Per Chapter

Create `Day NNN — review.md` here when a chapter enters 🔍 In Review. Format:

```markdown
# Day NNN — <Topic> — Review
Reviewers: Tech <name> · Story <name> · QA <name> | Draft date: YYYY-MM-DD

## 🔬 Technical (Track A)
- [P1|P2|P3] <section> — <finding> — *fixed in <edit note / waiver reason>*

## 🖋️ Story (Track B)
- [P1|P2|P3] <scene> — <finding>

## 🧹 QA (Quality Gate §13 + format)
- [P1|P2|P3] <item> — <finding>

## Sign-off
- Tech: — <name>, <date>
- Story: — <name>, <date>
- QA: — <name>, <date>
- Captain ✅: — <name>, <date>
```

Rules: [P1] blocks approval; [P2] blocks unless waived with a stated reason; [P3] never blocks. Cite section headings, not line numbers. Full conventions: [[fde by onepiece/05 Production Pipeline/04 Team Roles and Handoff|04 Team Roles and Handoff]].
