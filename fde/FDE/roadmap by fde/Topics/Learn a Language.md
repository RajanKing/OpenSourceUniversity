# Learn a Language

[[roadmap by fde/00 Start Here|Start Here]] / [[roadmap by fde/Tracks/02 Programming and Systems|02 Programming and Systems]] / [[roadmap by fde/01 Complete Topic Index|Complete Topic Index]]

## Meaning and FDE Relevance

Language proficiency means being able to build, debug, test, package, and operate a complete service, not only solve syntax exercises.

## Concepts to Understand

- Choose one primary language.
- Learn collections and error handling.
- Understand concurrency and I/O.
- Use dependency management and tests.
- Read stack traces and service logs.

## Applied Exercise

Build a command-line data audit and a small authenticated API that share validated domain models.

Use synthetic data and sandbox services. Do not connect customer systems, spend provider credits, or change production data without explicit authorization.

## Common Failure Mode

Switching languages repeatedly before being able to ship one complete, tested system.

## Evidence of Mastery

Implement and troubleshoot an end-to-end feature without relying on generated code you cannot explain.

- [ ] Explain the concepts and tradeoffs without reading the notes.
- [ ] Complete the exercise and retain a reproducible artifact.
- [ ] Test an error, permission, or recovery case where applicable.
- [ ] Record an observation, limitation, and next improvement.
