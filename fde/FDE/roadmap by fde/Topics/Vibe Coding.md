# Vibe Coding

[[roadmap by fde/00 Start Here|Start Here]] / [[roadmap by fde/Tracks/05 Agents and Coding Tools|05 Agents and Coding Tools]] / [[roadmap by fde/01 Complete Topic Index|Complete Topic Index]]

## Meaning and FDE Relevance

AI-assisted coding accelerates implementation only when a human retains control of requirements, verification, security, and maintainability.

## Concepts to Understand

- Give bounded tasks and relevant context.
- Inspect diffs.
- Run tests and type checks.
- Validate generated dependencies.
- Review authorization and secrets.
- Keep deployment approval outside model discretion.

## Applied Exercise

Use an assistant to implement one small feature, then explain every changed line and demonstrate a regression test.

Use synthetic data and sandbox services. Do not connect customer systems, spend provider credits, or change production data without explicit authorization.

## Common Failure Mode

Accepting code because it runs once, without understanding data access or failure behavior.

## Evidence of Mastery

The generated feature meets a written acceptance criterion and passes the same review gates as human-written code.

- [ ] Explain the concepts and tradeoffs without reading the notes.
- [ ] Complete the exercise and retain a reproducible artifact.
- [ ] Test an error, permission, or recovery case where applicable.
- [ ] Record an observation, limitation, and next improvement.
