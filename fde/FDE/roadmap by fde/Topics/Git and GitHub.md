# Git & GitHub

[[roadmap by fde/00 Start Here|Start Here]] / [[roadmap by fde/Tracks/02 Programming and Systems|02 Programming and Systems]] / [[roadmap by fde/01 Complete Topic Index|Complete Topic Index]]

## Meaning and FDE Relevance

Version control makes implementation history, review, collaboration, and rollback reproducible.

## Concepts to Understand

- Use small commits and branches.
- Read diffs and history.
- Resolve conflicts deliberately.
- Review pull requests.
- Protect default branches.
- Separate source code from secrets and generated artifacts.

## Applied Exercise

Deliver a feature through a pull request with tests, a migration note, and a rollback description.

Use synthetic data and sandbox services. Do not connect customer systems, spend provider credits, or change production data without explicit authorization.

## Common Failure Mode

Treating Git as cloud backup and merging changes without reviewing behavior or deployment impact.

## Evidence of Mastery

Another engineer can review, reproduce, and safely revert the feature.

- [ ] Explain the concepts and tradeoffs without reading the notes.

- [ ] Test an error, permission, or recovery case where applicable.
