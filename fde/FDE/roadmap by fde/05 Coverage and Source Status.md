## Important Boundaries

- Metadata retrieval and full-content review are different. The resource audit records this distinction for each URL.
- Selected source-content summaries are in Source Reading Notes. Other source notes are reading agendas, not source summaries.
- Authentication, payment, bot protection, unavailable pages, PDFs, and video transcripts can prevent full access.
- This original Canvas extraction did not recursively import related roadmaps. The separate Markdown export now includes the complete published topic and link metadata for all 44 directly linked roadmaps; it does not reproduce entire external learning sites.
- Existing vault files and Obsidian configuration were not modified.
- No models, customer databases, cloud deployments, paid subscriptions, or production writes were run.
